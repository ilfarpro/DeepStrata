# Moved

The Mac-first rebuild campaign (15 October 2026: implementation status, qualification kit, return packet and raw evidence) is finished.
It is kept whole in [history/docs/work](../../history/docs/work/IMPLEMENTATION_STATUS.md). Its results are the ones recorded on that day on one
development Mac; they say nothing about a later release. Release qualification uses the checks in [packaging/README.md](../../packaging/README.md).

is `deepstrata`. The pages are the record of that day on the original product, not instructions for today;
[DIVERGENCE.md](../../DIVERGENCE.md) lists what this fork keeps apart.
